# Safety Checklist – Iskra

## Przed pierwszym uruchomieniem

- [ ] Izolacja HV zmierzona
- [ ] Wyłącznik awaryjny działa i jest łatwo dostępny
- [ ] Hamulce (przód i tył) sprawne i odpowietrzone
- [ ] Łańcuch / pasek prawidłowo napięty i smarowany
- [ ] Koła i łożyska bez luzów
- [ ] Bateria solidnie zamocowana i nie przesuwa się
- [ ] Przewody HV zabezpieczone
- [ ] Test na stojaku przed jazdą

## Regularny serwis

- [ ] Stan opon, łańcucha, klocków hamulcowych
- [ ] Temperatury po jeździe
- [ ] Stan izolacji okresowo
- [ ] Dokręcenie krytycznych śrub ramy i wahacza
