# Zasady projektowe – Iskra

Te same fundamenty co ex-polonez i Elektron:

- Maintainability First
- Circular DIY + Low-Cost
- Metal tylko tam, gdzie konieczne
- Maksymalny druk 3D, spawanie DIY i upcycling
- Modularne baterie
- Łatwy serwis jedną osobą
- Pełna otwarta dokumentacja

Specyfika motocykla:
- Niska masa priorytetem
- Prosta geometria ramy rurowej
- Preferencja kontrolerów open-source typu VESC
- Łatwa wymiana koła / łańcucha / baterii
